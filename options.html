Settings

Getting started

  1. In the Wallet web app, open Settings → REST API and create an API token (needs Premium).
  2. Paste it below, press Load accounts, pick the Wallet account for your bank account, then Save settings.
  3. Open your bank's transaction history and click this extension's icon (or press Alt+Shift+W).

Want a look first? Open the side panel anywhere you're allowed and press Demo data: nothing is sent to Wallet.

Behaviour

Only open on supported sites The toolbar button opens the side panel only on a supported bank. Elsewhere it shows a short "not supported" message. Turn off to open it on any site.
Read transactions automatically Read the page when the panel opens and again whenever the page changes (next page, filters, another tab). Turn off to read only when you press the button.
Hide the panel when I switch away The panel hides when you switch to a tab where it isn't allowed, and returns when you come back. Turn off to keep it open as you switch tabs.
Collect transactions across pages Keep the transactions from every page you visit in the panel, so you can add several pages in one go. Use "Clear list" in the panel to start again. Off: the list shows only the current page.

Keyboard shortcut: Alt+Shift+W opens the panel. You can change it at chrome://extensions/shortcuts.

Transfer rules

When a bank description contains the words you enter, that row is created in Wallet as a transfer to the account you choose (Wallet adds the matching record on that account) instead of an ordinary expense. For example, "repayment" to your credit card. You can also turn any single row into a transfer in the panel.

Supported banks

    The side panel only opens on a supported bank's website. A bank marked as needing your permission asks for it the first time you use it there; you can also allow it here. Other banks would need their own page reader.
